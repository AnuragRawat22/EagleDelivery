1. Introduction & Formal Problem Formulation

The Eagle Delivery project addresses autonomous robotic delivery across the Eastern Michigan University campus. The simulated robot must transport packages between designated building entrances across discrete 2D grid campus layouts with building obstacles and walkable corridors. We explore two complementary computational paradigms: classical search (BFS and informed A* with Manhattan heuristic) when map models are known, and reinforcement learning (model-free tabular Q-learning with ε-greedy exploration) when navigation policies must be learned purely from environmental trial and error.

We formulate the campus delivery task as a deterministic discrete state-space planning problem:

  • State Space (S): Discrete coordinates s = (r, c) ∈ ℤ2 corresponding to traversable walkways (.) and building entrances (S, L, H, D, P, W). For an R × C map, S ⊂ {0, …, R-1} × {0, …, C-1} ∖ {s ∣ \text{grid}(s) = \text{'#'}}.
  • Initial State (s0): The grid coordinate (r0, c0) of the assigned pickup building entrance (e.g., Student Center S at (1, 1)).
  • Action Space (A): Four discrete cardinal movements: A = \{\text{UP}, \text{DOWN}, \text{LEFT}, \text{RIGHT}\}. Unit displacement vectors are Δ(a) ∈ \{(-1, 0), (1, 0), (0, -1), (0, 1)\}. Diagonal transitions are prohibited.
  • Transition Model (T(s, a)): Deterministic. Attempting action a from state s leads to s' = s + Δ(a) if s' is in-bounds and not an obstacle wall (#). If blocked or out-of-bounds, the robot remains in place (s' = s).
  • Goal Test (G(s)): Returns true if and only if s = s_{\text{goal}} = (r_g, c_g), matching the designated delivery destination building entrance. Intermediate building letters along the corridor are traversable and do not trigger termination.
  • Path Cost (c(s, a, s')): Every attempted action incurs a uniform unit cost of c = 1, regardless of movement success. The total path cost is the total number of actions: \text{Cost}(\pi) = \text{len}(\pi) - 1.
  • Optimality of BFS: Because all step costs are strictly positive and uniform (c = 1), Breadth-First Search systematically expands nodes in order of non-decreasing path depth. When BFS dequeues the goal state from its FIFO frontier, no undiscovered path can have fewer steps. Thus, BFS guarantees cost-optimality on unit-cost grid graphs.

2. Heuristic Admissibility Proof for Manhattan Distance

For A* graph search, the Manhattan distance heuristic (L1 norm) between current state s = (r_s, c_s) and goal g = (r_g, c_g) is:

h(s) = |r_s - r_g| + |c_s - c_g|
Definition (Admissibility): A heuristic h(s) is admissible if it never overestimates the true minimal cost h*(s) required to reach the goal from state s, i.e., ∀ s ∈ S, 0 ≤ h(s) ≤ h*(s).

Proof of Admissibility:

  1. Relaxed Problem Formulation: Consider an unobstructed relaxation of the grid map where all impassable obstacles (#) and map boundaries are removed, permitting unrestricted movement on the 4-connected 2D integer lattice ℤ2.
  2. Minimal Displacement Bound: To transition from (r_s, c_s) to (r_g, c_g), the agent must achieve a net vertical change of |r_s - r_g| and a net horizontal change of |c_s - c_g|. In any step t using cardinal actions, coordinate displacements satisfy |\Delta r_t| + |\Delta c_t| ≤ 1. Summing over all k steps along any valid trajectory:
    |r_s - r_g| = \left| \sum_{t=1}^k \Delta r_t \right| ≤ \sum_{t=1}^k |\Delta r_t|, \quad |c_s - c_g| = \left| \sum_{t=1}^k \Delta c_t \right| ≤ \sum_{t=1}^k |\Delta c_t|
    Adding these inequalities:
    |r_s - r_g| + |c_s - c_g| ≤ \sum_{t=1}^k (|\Delta r_t| + |\Delta c_t|) ≤ \sum_{t=1}^k 1 = k
    Thus, any valid path requires at least k ≥ |r_s - r_g| + |c_s - c_g| steps, meaning the true optimal relaxed cost is h*relaxed(s) = h(s).
  3. Obstacle Constrained Environment: In the real campus grid, obstacle walls can only block candidate routes and force longer detours; they can never provide shortcuts or allow diagonal traversal. Therefore, the true shortest path cost h*(s) in the constrained campus graph satisfies:
    h*(s) ≥ h*relaxed(s) = h(s)
  4. Consistency (Monotonicity): For any adjacent states s and s' with step cost c(s, a, s') = 1, the triangle inequality gives |h(s) - h(s')| ≤ |r_s - r_s'| + |c_s - c_s'| = 1 = c(s, a, s'). Hence, h(s) ≤ c(s, a, s') + h(s').

Since h(goal) = 0 and h(s) ≤ h*(s) for all s, the Manhattan distance heuristic is strictly admissible and consistent, guaranteeing that A* graph search finds an optimal path without re-expanding closed states. ▪

3. Part A: Classical Search Implementation & Empirical Comparison

We implemented BFS and A* in agents.py. A* maintains a priority queue of 4-tuples (f, insertion_number, g, state), where f = g + h. An insertion counter breaks f-ties deterministically in FIFO order without comparing state coordinates. A best_g lookup table tracks the cheapest known cost to each state, lazily skipping stale queue entries whose stored g exceeds best_g[state]. Successors are expanded in the campus order: UP, DOWN, LEFT, RIGHT.

In-Depth Analysis and Discussion

  1. Route Length Equivalence: In all six test cases, BFS and A* discover routes of identical step counts (18, 22, 16, 26, 22, 16). This empirically validates our theoretical proof that both algorithms guarantee cost-optimality under uniform positive edge costs with an admissible heuristic.
  2. Walkway Detour Impact: In emu_detour.txt, cell (3, 6) is obstructed. For the S → W delivery task, this cell lies directly along the baseline primary artery, forcing the robot around the central building block and extending the optimal route by 8 steps (from 18 to 26). In contrast, tasks L → D and H → P remain completely unaffected in route length (22 and 16 steps respectively) because their optimal paths do not traverse coordinate (3, 6).
  3. Search Efficiency and Heuristic Guidance: A* expands substantially fewer nodes than BFS across all tasks. Most impressively, on H → P (both baseline and detour), A* expands exactly 16 nodes—identical to the route length. Because the corridor between H and P is relatively unobstructed in the goal direction, h(s) = h*(s) along the path, allowing A* to proceed directly to Putnam Hall with zero extraneous exploration. For S → W on the baseline map, A* reduces node expansions from 67 to 22 (a 67.2% reduction).
  4. Theoretical Insight: Does A* Always Expand Fewer Nodes Than BFS? A* is not guaranteed to expand fewer nodes than BFS in every arbitrary configuration. When an environment contains deep concave obstacles ("cul-de-sacs" or U-shaped walls) whose opening faces away from the goal, an admissible heuristic draws A* deep into the dead-end trap because geometric distance decreases. A* must exhaustively expand the interior trap until f = g + h rises sufficiently to explore the escape route. In contrast, BFS expands outward in spherical shells and may encounter the escape path before A* overcomes its heuristic trap. On realistic campus maps, however, A*'s goal-directed pruning provides massive performance gains.

4. Part B: Model-Free Q-Learning Formulation & Baseline Evaluation

When campus maps are unavailable, the robot learns optimal policies through trial and error. The environment provides a step reward r = -1 for every attempted action and a +40 delivery bonus upon arrival (r = 39 on the terminal step). An episode terminates on arrival or after 200 actions, giving an undiscounted return of R = 40 - L for an L-step route.

We implemented tabular Q-learning with ε-greedy action selection. State-action pairs are stored in a dictionary initialized to 0.0. The off-policy Bellman update is:

y = r \quad (\text{if terminal}), \quad y = r + \gamma \max_{a' \in A} Q(s', a') \quad (\text{otherwise})
Q(s, a) \leftarrow Q(s, a) + \alpha [y - Q(s, a)]

Baseline training hyperparameters: \alpha = 0.3 (learning rate), \gamma = 0.95 (discount), \epsilon = 0.20 (exploration), 2,000 episodes per seed across seeds 0, 1, 2. Evaluation freezes learning (\alpha = 0) and tests 100 greedy episodes (\epsilon = 0) per seed.

5. Part C: Custom Campus Design & Epsilon-Variation Study

Custom Campus Map (maps/my_campus.txt): A 10 \times 15 grid containing all six buildings: S at (1,1), W at (1,12), L at (5,1), D at (5,13), H at (9,1), and P at (9,12). The map features an unobstructed northern corridor (optimal S→W length 11 steps), an internal cyclic loop connecting north and south campus, and deceptive dead-end branches. On S→W, BFS took 35 expansions while A* took only 11 expansions.

Key Insights: 1) Off-Policy Optimality: As predicted, all three agents learn the identical globally optimal greedy policy (11 steps, 29.0 return) because Q-learning's target relies on \max_{a'} Q(s', a') rather than the action chosen by the behavior policy. 2) Online Training Dithering Penalty: Under \epsilon = 0.50, taking 50% random exploratory actions causes extensive dithering during training, depressing online returns to \approx 16.0 (averaging \approx 24 steps/episode). Under \epsilon = 0.05, the agent exploits its knowledge 95% of the time, achieving high online returns (\approx 28.4) while still exploring enough to solve the map.

6. Conclusion

This project demonstrated the complementary strengths of heuristic planning and reinforcement learning. With map access, A* guided by the admissible Manhattan distance reduces search expansions by up to 67.2% while guaranteeing path optimality. In unknown environments, tabular Q-learning converges reliably across diverse initializations to the exact same optimal shortest routes. Controlled experiments confirmed that while exploration rate ε heavily dictates transient online operational efficiency, Q-learning's off-policy foundation ensures robust asymptotic convergence to optimal navigation.
